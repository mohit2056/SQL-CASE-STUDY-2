# SQL Case Study - MySQL

This repository contains MySQL DDL, sample data and solution queries for the SQL case study.

## Files
- `schema_and_data.sql` — creates tables and inserts sample data.
- `queries.sql` — all solution queries grouped by topic.
-  screenshots for better understanding
## How to run
1. Open MySQL client or MySQL Workbench.
2. Run `schema_and_data.sql` to create schema and load data.
3. Run queries from `queries.sql` as needed.

## Notes
- Dates use `YYYY-MM-DD` format for MySQL.
- Adjust data types or constraints if you use a different MySQL version.
